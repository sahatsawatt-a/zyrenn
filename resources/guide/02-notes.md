# Notes

A note is a page made of blocks: a paragraph, a heading, a list, a table, a picture. Write as you would anywhere; reach for a block when you need more than text.

<video src="/images/guide/tour-note.webm" title="Show me: Write a note"></video>

## Add a block

Type **/** on an empty line and pick from the menu, or keep typing to narrow it.

![The menu of blocks that opens when you type a slash](/images/guide/notes-menu.png)

| Type             | To get                                                 | More                                                        |
| ---------------- | ------------------------------------------------------ | ----------------------------------------------------------- |
| /heading, /to-do | Headings, lists, to-dos, quotes and callouts           | [Text, headings and lists](/guide/notes/writing)            |
| /table           | A small table inside the note                          | [Tables in a note](/guide/notes/tables)                     |
| /image, /video   | A picture or a video: uploaded, from the Drive, a link | [Pictures and videos](/guide/notes/pictures-and-videos)     |
| /code            | Code, coloured by its language                         | [Code](/guide/notes/code)                                   |
| /equation        | A formula written in LaTeX                             | [Math](/guide/notes/math)                                   |
| /mermaid         | A diagram drawn from a few lines of text               | [Mermaid diagrams](/guide/notes/mermaid)                    |
| /circuit         | A schematic from its parts and wires                   | [Circuits](/guide/notes/circuits)                           |
| /graph           | Curves from formulas, with sliders                     | [Graphs](/guide/notes/graphs)                               |
| /timing          | Signals over time: a clock, a bus                      | [Timing diagrams](/guide/notes/timing)                      |
| /reveal          | An answer kept out of sight until clicked              | [Reveal](/guide/notes/reveal)                               |
| /value           | A number from a table or a trip, kept up to date       | [Live values](/guide/notes/live-values)                     |
| /board, /trip    | Another page, shown in the note                        | [Links and other pages](/guide/notes/links-and-other-pages) |

Each has a page of its own below, with examples drawn the way a note draws them.

## Move and change blocks

Hover a block and use the handle to its left: drag it to move the block, or open it for the block's menu.

## Saved as you go

The bar above the note says whether it is saved and who else has it open. There is no Save button. In a project, everyone with the note open writes in the same copy. Version history and PDFs are in [History, PDF and writing together](/guide/notes/history-and-pdf).
