# Getting started

Zyrenn keeps your writing, drawings, data, places and files in one place, and lets them show each other. Each kind of thing has its own screen in the sidebar.

## What is where

| In the sidebar | What it holds                                                       |
| -------------- | ------------------------------------------------------------------- |
| Notes          | Pages of writing: text, lists, tables, pictures, diagrams, formulas |
| Boards         | Endless whiteboards of shapes, sticky notes, arrows and frames      |
| Tables         | Rows and columns, each column of one kind                           |
| Maps           | Places you have saved                                               |
| Trips          | Travel plans: flights, hotels, and each day's stops in order        |
| Drive          | Your files                                                          |
| Workflows      | Steps that run on their own                                         |
| Chat           | Your chat rooms, and messages with other people                     |
| Tickets        | In a project: the bugs and features it has been asked for           |
| Guide          | This guide                                                          |

## Your dashboard

The **Dashboard** picks up where you left off: what you changed lately, what people changed in your projects, the to-dos still open in your notes, your unread messages, and your projects. Start a new note, board or table from the top of it.

## Your own space, and projects

What you make is yours alone until you put it in a **project**. A project is a shared space with notes, boards, tables and a Drive of its own.

- Switch between your own space and a project at the top of the sidebar.
- Everyone in a project is an **owner**, an **editor** or a **viewer**. Viewers can read; owners and editors can change things.
- A note or board in a project can be edited by several people at once.
- A project has **Tickets**: the bugs to fix and features to add it has been asked for. See Projects and tickets.

## Folders and search

Every screen has its own folders. Drag something onto a folder to move it. The search box looks through every folder at once.

:::callout 💡
Things can show each other: a note can hold a board, a trip, a map, or a number from a table that stays up to date. Type **/** in a note to see what it can hold.
:::

## Make your first board

A board takes a minute to start: make it, name it, and drag a sticky note onto it. Boards has the rest.

## Using it from an AI client

Claude and other AI clients can read and write your notes, boards, tables and trips. Set it up under **Settings**, then **MCP**: see Settings and AI clients.

Settings is also where you choose a light or dark look, under **Appearance**.
