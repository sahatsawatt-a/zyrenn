# Fields

Each column of a table is a **field**, and holds one kind of value. Add one from **Field** above the table, or from the **+** at the end of the header row: give it a name, such as Status, Due date or Budget, and choose its kind.

| Kind               | Holds                           | Set up with                |
| ------------------ | ------------------------------- | -------------------------- |
| Text               | A line of words                 |                            |
| Long text          | Paragraphs                      |                            |
| Number             | Whole numbers                   |                            |
| Decimal            | Numbers with a point            |                            |
| Currency           | Money                           | Its symbol                 |
| Percent            | A share, shown with %           |                            |
| Checkbox           | Yes or no                       |                            |
| Select             | One of a list of your own       | Its choices, each a colour |
| Multi-select       | Several of a list of your own   | Its choices, each a colour |
| Date               | A day                           |                            |
| Rating             | Stars                           | How many it is out of      |
| Email, Link, Phone | An address, opened when clicked |                            |
| Person             | Someone in the project          |                            |
| Location           | A place on the map              |                            |
| Formula            | A value worked out from the row | Its formula (see Formulas) |

A number field can also choose what goes **under the column**: its sum, average, smallest, largest or count.

## Change a field

Open a field's menu from its header to **Edit field**, sort by it, hide it, duplicate it or delete it. A field can only change to a kind its values can be kept as.

Drag a column's edge to make it wider or narrower, or double-click the edge to fit what is in it. **Fields**, above the table, shows and hides fields.

## Rows

**Row** adds a row; so does **New row** under the last. Click a cell to change it. Tick rows at their left to duplicate or delete them together, and **Ctrl + Z** undoes a change.
