# Search, filter and sort

## Search

**Search rows** looks through every field at once, and shows only the rows that match.

## Filter

**Filter** shows only the rows where a field meets a test. Add as many as you need; a row has to meet them all.

| Test                       | For                           |
| -------------------------- | ----------------------------- |
| contains, does not contain | Words in a text field         |
| is, is not                 | One value exactly             |
| >, <                       | Numbers and dates             |
| is empty, is not empty     | Whether it has been filled in |

## Sort

**Sort** orders the rows by one field, from low to high or high to low. A field's own menu sorts by it too; empty cells go last.

## What is shown

- **Fields** shows and hides fields.
- **Row height**: compact, normal or spacious.
- The sums under columns count only the rows on show, so a search or a filter narrows them.

## Export

**Export** downloads the rows on show, with the fields on show, as a CSV file for a spreadsheet.
