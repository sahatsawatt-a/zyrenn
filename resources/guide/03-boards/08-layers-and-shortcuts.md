# Layers, shortcuts and touch

## Layers

**Layers** lists everything on the board, frame by frame. From there:

- **Hide** something while you work around it, and **Show** it again.
- **Lock** it, so it stays where it is however much is dragged around it.
- Hide a frame **in PDF** only.
- Drag a row to change what is in front of what.

## Keys

| Keys                       | Do                             |
| -------------------------- | ------------------------------ |
| Space + drag               | Move the board                 |
| Scroll, or pinch           | Zoom                           |
| Shift + scroll             | Move sideways                  |
| V, S, T                    | Select, sticky note, text      |
| R, O, M                    | Rectangle, ellipse, decision   |
| A, D, F, E                 | Connector, pen, frame, formula |
| Esc                        | Back to Select                 |
| Double-click, Enter        | Write on a shape, finish       |
| Shift + click              | Add to the selection           |
| Ctrl + D                   | Duplicate                      |
| Delete                     | Remove                         |
| Ctrl + ], Ctrl + [         | Forward, backward              |
| Ctrl + Z, Ctrl + Shift + Z | Undo, redo                     |

The keyboard button at the top of the board lists them all.

## A phone or a tablet

Drag the bare board with one finger to move it, and pinch with two to zoom. On a small screen the bar folds the tools it has no room for under **More**.

## In the dark

When the app is dark, so is the board's background. What is on the board keeps its own colours, so a board looks the same to everyone.
