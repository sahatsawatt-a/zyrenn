# Formulas on a board

The **Formula** tool (**E**) puts a formula anywhere on the board, written in LaTeX and set by KaTeX: $F = ma$, $\frac{1}{2}mv^2$, $\sum_{i=1}^{n} x_i$.

Double-click it to change the LaTeX. It grows and shrinks with the board as you zoom.

For what can be written, see Notes, then Math.
